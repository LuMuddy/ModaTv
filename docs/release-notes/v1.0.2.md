v1.0.2

这一版是第一次由 GitHub Actions 自动构建、自动签名并发布的包。

变化
- 安装包文件名改为 ModaTv1.0.2.apk（去掉了中间的连字符），应用内更新的下载地址已同步
- versionCode 改由 tag 推导：1.0.2 → 10002，与本地构建的编号规则一致
- 签名与上一版相同（同一把密钥），可以直接覆盖安装

如果你是从 1.0.0 / 1.0.1 升级
- 旧版按带连字符的旧文件名拼下载地址，这一版改了名字，所以旧版里点「立即更新」会下载失败
- 手动装一次这一版即可，之后自动更新恢复正常

完整对比：https://github.com/LuMuddy/ModaTv/compare/0a20381...v1.0.2
